# lxd: `lx` helper

Short wrapper around `lxc` for everyday LXD container ops.

- Subcommands: `ls`, `bash`, `sh`, `cp`, `rm`, `start`, `stop`, `snap`
- `lx snap` sub-subcommands: `new`, `ls`, `restore`, `rm`

Run `lx help` for the full command list with examples.

## Prerequisites

- bash
- `lxc` CLI; LXD installed and the user added to the `lxd` group
